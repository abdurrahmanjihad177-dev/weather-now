# WeatherNow – Next.js Weather App

Simple weather app built with **Next.js (App Router)**, **Tailwind CSS** and the free **Open-Meteo API**.

## Features
- 4 pages: Home, About, Services, Contact
- Header & Footer as reusable components
- Live Temperature, Humidity, Wind Speed, Time and Interval
- City selector (Dhaka, Gazipur, Chattogram, Sylhet, Rajshahi)
- Fully responsive (mobile menu included)

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build
```bash
npm run build
npm start
```
